# Salud y Estética en tu Hogar

Sitio web de un servicio de **enfermería y estética a domicilio** en Santiago, con atención personalizada y solicitud de horas por WhatsApp.

**Sitio en vivo:** https://enfermeria-website.vercel.app/

## Secciones

- Servicios de enfermería y servicios estéticos
- Atención a domicilio por comuna
- Cómo solicitar una atención
- Contacto directo por WhatsApp

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Despliegue en Vercel

## Cómo ejecutarlo

```bash
npm install
npm run dev      # servidor de desarrollo
npm run build    # build de producción
```
